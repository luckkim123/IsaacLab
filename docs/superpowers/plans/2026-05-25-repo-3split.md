# Repo 3-Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the single `/workspace/isaaclab` tree into three layered repos — `isaaclab` (clean upstream fork), `marinelab` (public overlay extension), `constrained-albc` (private research overlay) — without losing functionality or git history value.

**Architecture:** External-extension overlay. `marinelab` and `constrained-albc` self-register their Gym environments via their own `pyproject.toml` entry-points, so the `isaaclab` fork stays a zero-touch clean fork. Bottom-up migration: isaaclab clean → marinelab → constrained-albc. The current tree remains source of truth until each phase is verified.

**Tech Stack:** Python 3.12, IsaacLab v2.3.0, Isaac Sim 5.1, RSL-RL, gymnasium, Git LFS, git filter-repo, Docker.

**Design spec:** `docs/superpowers/specs/2026-05-25-repo-3split-design.md`
